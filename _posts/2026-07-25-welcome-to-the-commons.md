This site works a little differently from most blogs. There's no sign-up form, no dashboard, no password to lose. If you want to publish here, you write a Markdown file and open a pull request.

## Why this way

Static sites are fast, free to host, and nearly impossible to break into — there's no database to leak and no login system to secure. The trade-off is that "publishing" usually means only the site owner can push new content.

Using GitHub's pull request flow turns that limitation into a feature: anyone can propose a post, and a lightweight review step keeps quality and tone consistent, the same way an editor would at any real publication.

## How to contribute

Check the `CONTRIBUTING.md` file in this repository for the full walkthrough. In short:

1. Fork the repo
2. Add a new file in `_posts/` following the naming pattern `YYYY-MM-DD-title.md`
3. Fill in the front matter (title, subtitle, author, tags)
4. Open a pull request

Once it's merged, your post goes live automatically.
